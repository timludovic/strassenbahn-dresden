# Export — ZF

Fünf Zeichen, je in Farbe und invers. Alle Dateien sind eigenständige SVGs,
200 × 200 Einheiten, transparenter Grund, ohne Seite und ohne CSS.

| Datei | Inhalt | Verwendung |
|---|---|---|
| `zeichen.svg` | Gleis-Zeichen (zwei Winkel, Fuge) | App-Icon, Favicon, Bildmarke |
| `wortmarke-zf.svg` | Wortmarke `zf.` | Kopfzeile, Splash |
| `zusammenfahren.svg` | Schriftzug `zusammenfahren.` | Claim, Kampagne |
| `sperrung-zf.svg` | Zeichen + `zf.` | volle Marke, horizontal |
| `sperrung-zusammenfahren.svg` | Zeichen + Claim | Marke mit Aussage |
| `*-invers.svg` | dieselben Zeichen in Creme | auf dunklem Grund |

**Farben:** Tiefgrün `#0B4A2F` · Minze `#6FE3A6` (nur Punkt) · Creme `#EDF7F0`

**Schrift:** Inter, Gewicht 800, Laufweite −12 (zf.) bzw. −1 (Claim).
Die SVG-Dateien setzen die Schrift als Text; für Druck und Fremdsysteme in der
Design-Software in Pfade umwandeln. Das Zeichen ist reine Geometrie und braucht
keine Schrift.

**Fuge:** Die Lücke im Zeichen ist eine Maske, kein weißer Strich — sie bleibt
auf jedem Grund transparent.

**Rasterfassungen:** App-Icons (`icon-64/256/512/1024.png`) und die beiden
Instagram-Profilbilder (1080 × 1080 px, JPEG) liegen im Exportpaket neben den
SVGs.
